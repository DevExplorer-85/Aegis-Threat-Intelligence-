Chunking policy

Paragraph-aware report text is normalized and split into 900-word windows with 120-word overlap. Existing passage page numbers are preserved.

Embedding safety

Every vector stores model and dimension metadata. Queries reject incompatible index dimensions and indexing blocks an embedding-model mismatch.
